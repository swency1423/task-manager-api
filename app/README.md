# Task Manager REST API

A beginner-friendly task management API built using
Python, FastAPI, SQLAlchemy, and SQLite.

## Features
- Create tasks
- View all tasks
- View a task by ID
- Update tasks
- Delete tasks
- Handle invalid task IDs

## Technologies
- Python
- FastAPI
- SQLite
- SQLAlchemy
- Swagger UI

## Installation

1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Start the server:

   uvicorn main:app --reload

4. Open http://127.0.0.1:8000/docs
